## 1. Название и организация

- **Название системы:** Система учёта заявок на ремонт компьютерного оборудования.
- **Организация / подразделение:** Компьютерные классы Казанского государственного энергетического университета (учебная модель организации).
- **№ из таблицы примеров:** Своя тема на основе процесса ремонта оборудования. Специализация — компьютерное и мультимедийное оборудование.

## 2. Главная сущность и справочник

- **Главный объект (одна запись процесса):** Заявка на ремонт оборудования (`Ticket`).
- **Справочник (вторая таблица, ссылка числом):** Справочник компьютерного и мультимедийного оборудования (`Equipment`).
- **Поле-ссылка (как назовёте в JSON/БД):** `equipmentId`.

Каждая заявка относится к конкретной единице оборудования из справочника.

## 3. Роли и права

| Роль | Создаёт | Назначает | Меняет статус |
|------|---------|-----------|---------------|
| Сотрудник | да | нет | нет |
| Администратор | нет | да | да |
| Технический специалист | нет | нет | да |
| Руководитель | нет | нет | нет |

Администратор назначает исполнителя и может отменить заявку. Технический специалист меняет статус только назначенных ему заявок. Сотрудник создаёт заявку, но не может самостоятельно закрыть её.

## 4. Сценарий в одно предложение

Сотрудник создаёт заявку на ремонт компьютерного или мультимедийного оборудования → администратор назначает технического специалиста → назначенный специалист выполняет ремонт и изменяет статус заявки до завершения работы.

## 6. Что не входит в семестр

1. Разработка отдельного мобильного приложения для Android и iOS.
2. Автоматическая интеграция с системой бухгалтерского учёта 1С.
3. Учёт закупок, финансов и складских запасов оборудования.
4. Автоматическое управление оборудованием и диагностика неисправностей через датчики.
5. Отправка SMS-уведомлений и интеграция с платёжными системами.
6. Физическое выполнение ремонтных работ.

В рамках семестра разрабатывается только информационная система для регистрации, распределения и контроля заявок.

## 7. Запас под ВКР

Возможные направления дальнейшего развития, которые не входят в текущий семестровый проект:

1. **Данные и процессы:** внедрение аналитики для выявления наиболее частых неисправностей и прогнозирования потребности в ремонте.
2. **Интеграции:** подключение корпоративной электронной почты для автоматического уведомления сотрудников о состоянии заявок.
3. **Интеграции:** интеграция с системой учёта имущества университета для автоматического получения информации об оборудовании.
4. **Масштабирование:** расширение системы на несколько учебных корпусов с раздельным учётом оборудования и заявок.

## 8. Чем не копия соседа

Проект ориентирован на обслуживание компьютерного и мультимедийного оборудования учебных классов образовательной организации. Главным объектом является заявка на ремонт конкретной единицы оборудования, а основными участниками процесса выступают сотрудник, администратор, технический специалист и руководитель. Отличительной особенностью является связь каждой заявки с отдельной записью справочника оборудования через поле `equipmentId`.
