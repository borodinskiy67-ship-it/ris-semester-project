
# Отчет по лабораторной работе №7

## Проверки
- `dotnet --version` работает.
- Проект находится в `/backend`.
- `dotnet run` проходит.
- HTTP-порт равен 5000.
- Swagger открывается в Development по адресу `http://localhost:5000/swagger`.
- GET `/health` возвращает 200 и `Healthy`.
- GET `/info` возвращает JSON с данными о приложении.

## Чеклист «/health ≠ создание»
- `/health` возвращает 200 без тела заявки — **да**.
- `/health` не принимает title, equipmentId, description — **да**.
- Успешный `/health` не доказывает работу POST — **да**.
- Создание главного объекта относится к ЛР8 — **да**.
- README прямо объясняет это различие — **да**.
- Swagger и `/health` проверены отдельно — **да**.

## DI
Сервис зарегистрирован через DI в `Program.cs` (`AddSingleton`), чтобы контроллеры не создавали реализацию через `new`. Полный CRUD пока не пишем.
