| Сценарий | Что делаю | Результат |
|----------|-----------|-----------|
| Успех | Заполняю форму корректно, нажимаю «Создать» | Кнопка блокируется, текст меняется на «Создаём...», затем переход на `/`, заявка в списке (статус «Новая»). |

## Проверка Network (F12)
При включенном `USE_MOCK = true` запросов в Network нет — это нормально (имитация). 
При выключенном `USE_MOCK` в Network видно обращение к `http://localhost:5000` и ошибка сети (сервер не запущен).

*Скриншоты прилагаются (вставить сюда скрин Network при необходимости).*
