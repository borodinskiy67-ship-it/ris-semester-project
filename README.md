# Система учёта заявок на ремонт компьютерного оборудования

## Общая информация

**Название проекта:** Система учёта заявок на ремонт компьютерного оборудования.

**Автор:** Бородинский Дмитрий Анатольевич

**Группа:** ТРИС-2-23

**Дисциплина:** Разработка информационных систем

## Описание проекта

Веб-приложение предназначено для регистрации, обработки и контроля заявок на ремонт компьютерного и мультимедийного оборудования образовательной организации.

Система позволяет сотрудникам создавать заявки о неисправностях, администраторам распределять заявки между техническими специалистами, а исполнителям отслеживать ход выполнения ремонтных работ.

## Основные технологии

- Frontend: Vue 3.
- Backend: ASP.NET Core.
- База данных: PostgreSQL.

## Основные роли пользователей

- Сотрудник — создаёт заявки и отслеживает их состояние.
- Администратор — управляет заявками и назначает исполнителей.
- Технический специалист — выполняет ремонт и изменяет статус заявок.
- Руководитель — просматривает информацию о заявках и статистику.
